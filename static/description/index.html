Quick Installation

Get started in minutes with these simple steps

1

Install Module

Go to Apps menu in Odoo, update the apps list, and search for "BizVibe Smart AI"

2

Configure API

Navigate to Settings → General Settings and enter your BizVibe API credentials

Optional: Works with mock data for testing
3

Start Searching

Click "BizVibe Intelligence" from the main menu or use the enrich button on any Contact/Lead

4

Import & Enrich

Select companies from search results and import them as Contacts or Leads with one click
